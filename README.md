# Heichal Walkthrough: desktop releases

Installers for the offline desktop version of the Beis HaMikdash 3D walkthrough (Windows and Mac).
Download the latest from the [Releases](../../releases/latest) page.

- Windows: run `HeichalWalkthrough-Setup-<version>.exe`. The installer is unsigned, so Windows shows "Windows protected your PC": choose More info, then Run anyway.
- Mac (Apple Silicon): open the `.dmg` and drag the app to Applications. The app is unsigned, so the first time, right-click it and choose Open.

The app runs fully offline. It checks this page for a newer version when it starts and asks before downloading one.
